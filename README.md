# OpenNeuronic.Pipes
OpenNeuronic.Pipes is a Python-first, horizontally scalable, containerised data movement and transformation platform designed to move data between relational systems such as SQL Server and PostgreSQL, while remaining extensible to additional sources and sinks over time.

# OpenNeuronic commitment to open-source
Open source is not just about making code public; it is about making progress collaborative, transparent, and accessible to anyone willing to contribute.
